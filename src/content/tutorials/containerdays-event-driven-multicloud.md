# ContainerDays: Beyond Tool Sprawl, An Event-Driven Approach to Dynamic Multi-Cloud Operations

Presented by Eleni Grosdouli. Teams juggle many tools, CLIs and workflows across different environments, and wait for resources such as databases, secrets and applications.

The talk introduces an event-driven approach to multi-cloud operations: Sveltos, an open-source tool for declarative operations, spins up services on demand, manages deployments and keeps everything consistent using GitOps principles. Configurations stay adaptable and reusable for any environment, and service creation is automated with workflows.
