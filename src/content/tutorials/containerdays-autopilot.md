# ContainerDays: AutoPiloting Kubernetes, how we built autonomous Control Planes

Presented by Dario Tranchitella and Gianluca Mardente. Clusters are no longer static entities, they are dynamic, and managing them at fleet scale needs more than GitOps and static desired-state.

The talk introduces the AutoPilot model: with Kamaji and Project Sveltos, control planes are decoupled from infrastructure, and cluster configuration is intent-driven and event-aware. Hosted Control Planes with Dynamic Add-Ons orchestration let clusters configure themselves, adapt to runtime conditions and keep reconciling toward operational intent without manual intervention.
